🎯 1 — Problem & Tujuan

Problem lu sekarang

  • Ambil barang affiliate asal comot → terjual 12 biji → gak ada komisi
  • Butuh bukti bayar: terjual, rating, harga, komisi — bukan cuma "viral di FYP"
  • Bikin video TikTok/Shopee Video untuk barang yang salah = boncos waktu

Tujuan app Android

  • Input: kategori bebas (parfum, hijab, skincare) + filter terjual/rating/harga
  • Proses: scrape publik shopee.co.id/search?keyword= → parse terjual/rating → scoring log10(terjual) × rating + komisi est (harga × rate)
  • Output: ranking OP → link affiliate siap tempel + Excel rapi
Batasi scope: v1 hanya Shopee. TikTok Shop fee anti-bot keras & butuh login — rawan ke-blok pas demo. Shopee work 100% + bisa dipakai untuk TikTok affiliate juga (barang sama).

🏗️ 5 — Arsitektur Android

Stack

  • Module: data/remote/ShopeeRemote → domain/ScoreCalculator → data/local/Room → ui/
  • Build: Gradle + GitHub Actions (testDebugUnitTest + lintDebug → assembleRelease)

Rumus Scoring v1

  • score = log10(terjual+1) × rating × hargaFactor
  • hargaFactor = 1.0 jika 50k-300k, 0.7 jika di luar
  • komisi_est = harga × rate (rate 0.08 default, user bisa ganti 0.05/0.10/0.15)
  • Sorting score DESC → top 20
